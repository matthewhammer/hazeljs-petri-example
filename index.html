Petri nets, with rules in Hazel

source on GitHub · hazeljs on npm · how it works

The page keeps the net and draws it; a Hazel program decides what each event does. Click a transition to fire it, or step at random. The rules below are in Hazel's own editor: change them, and the page builds them again with hazeljs. While they have an error or a hole, the page's own JavaScript answers instead, and the log says which did.

⏳ The net is drawn from its definition in Hazel (the module Main, with the rules), once hazeljs has built it.

This app needs JavaScript, and a page served over http (python3 -m http.server, then localhost): Hazel's editor frames take no file:// page.
